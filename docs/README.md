Данная утилита - упрощённый вариант утилиты cat в Unix-подобных ОС для вывода информации из файлов.
Это экспериментальная утилита.
Использование: MCat [КЛЮЧ]… [ФАЙЛ]… Печатает слияние ФАЙЛ(ов) на стандартный вывод.
-b - нумеровать непустые строки при выводе;
-E - показывать $ в конце каждой строки;
-n - нумеровать все строки при выводе;
-T - показывать символы табуляции как ^I.

ВАЖНО:
невозможно одновременное использование ключей -b и -n.
